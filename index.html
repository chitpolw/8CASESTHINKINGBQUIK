CASE 01

รถสั่นหลังรับรถ

ข้อมูลเพิ่ม → ยืนยันสีเดิม

🟨 Yellow
→
🟨 Yellow

ข้อมูลชุดที่ 1 — Layer 1

ลูกค้าแจ้งว่ารถสั่นตอนจอดติดเครื่องหลังรับรถ และกังวลว่ากลับไปแล้วรถอาจมีปัญหา

ตอนนี้ยังไม่มีข้อมูลว่ารถมีความเสียหายรุนแรง หรือมีความเสี่ยงด้านความปลอดภัย

🟨 Layer 1 → Yellow มีอาการที่ต้องตรวจสอบ แต่ข้อมูลที่มีตอนนั้นยังไม่ชี้ว่ามีความรุนแรงสูง ผลกระทบหลักคือความกังวลของลูกค้า

① ความเสียหาย

1

มีอาการจริง แต่ยังไม่พบความเสียหายรุนแรง

② ผลกระทบ

0

ผลกระทบหลักยังเป็นความกังวล และยังไม่มีความเสียหายต่อการใช้งาน

③ การขยายวง

0

ลูกค้ากับพนักงานยังพูดคุยและจัดการแนวทางได้

④ ความเสี่ยง

1

ยังมีความเสี่ยงที่ต้องตรวจสอบ แต่ยังไม่ชัดว่าเป็นความเสี่ยงรุนแรง

รวมคะแนน: 2
🟨 Yellow

ข้อมูลชุดที่ 2 — Layer 2

ช่างตรวจแล้วพบว่าอาการสั่นมีจริง แต่ยังไม่พบปัญหาที่ทำให้รถอยู่ในภาวะอันตราย

มีการนัดลูกค้านำรถกลับมาตรวจเพิ่มเติมในวันถัดไป ลูกค้ารับรู้และยอมรับแนวทาง

🟨 Layer 2 → Yellow ข้อมูลใหม่ยืนยันว่าอาการมีจริง แต่ยังไม่พบความเสี่ยงด้านความปลอดภัย มีแผนตรวจเพิ่มเติมและลูกค้ายอมรับแนวทาง
LEARNING POINT

VERIFY ไม่ได้มีไว้เพื่อหาว่าจะยกระดับอย่างเดียว แต่มีไว้เพื่อให้เรามั่นใจว่า ระดับที่เราเลือกนั้นเหมาะสมกับข้อเท็จจริงจริง ๆ

💬 ชวนกลุ่มคุย

① เราเห็นอะไรเหมือนกัน? “ข้อมูลอะไรที่ทำให้เราคิดตรงกัน?”
② เราเห็นต่างตรงไหน? “มีข้อมูลส่วนไหนที่เราอาจตีความต่างกัน?”
③ ถ้าเราได้ข้อมูลเพิ่มอีก 1 อย่าง เราอยากรู้อะไร? “ข้อมูลอะไรที่จะทำให้เราตัดสินใจเปลี่ยนสีได้?”

ข้อมูลชุดที่ 1 — Layer 1

ลูกค้ามารับรถตามเวลาที่แจ้งไว้ แต่รถยังไม่พร้อมส่งมอบ

ลูกค้าต้องไปรับลูกตอน 18.00 น. และกังวลเพราะยังไม่รู้ว่าจะได้รถเมื่อไร

🟨 Layer 1 → Yellow ตอนแรกเป็นเรื่องงานล่าช้าและความไม่แน่นอน ยังไม่มีข้อมูลว่าผลกระทบขยายไปมากกว่านั้น

① ความเสียหาย

0

ยังไม่มีความเสียหายต่อรถหรือทรัพย์สินที่ระบุไว้

② ผลกระทบ

1

ลูกค้าได้รับผลกระทบจากความล่าช้าและไม่สามารถวางแผนได้

③ การขยายวง

0

ยังไม่มีข้อมูลว่าปัญหาขยายไปถึงบุคคลอื่น

④ ความเสี่ยง

1

มีความเสี่ยงว่าผลกระทบจะเพิ่มขึ้น หากลูกค้ายังไม่ได้รถตามเวลา

🟨 Yellow

ข้อมูลชุดที่ 2 — Layer 2

งานซ่อมยังไม่สามารถส่งมอบรถได้ตามเวลาที่คาดไว้

สามีของลูกค้าออกจากงานไม่ได้ ลูกอยู่ที่โรงเรียน และลูกค้าต้องไปเอาลูกเองโดยไม่มีรถคันอื่น

🟧 Layer 2 → Orange เรื่องไม่ได้เป็นเพียง “รถเสร็จช้า” แล้ว แต่เริ่มกระทบการดำเนินชีวิตของลูกค้าอย่างชัดเจน และต้องมีผู้จัดการเข้ามารับผิดชอบ
LEARNING POINT

ข้อมูลใหม่ทำให้เราเห็น “ผลกระทบจริง” ที่ตอนแรกยังไม่เห็น จึงต้องทบทวนระดับของเคส ไม่ใช่ยึดสีเดิมเพียงเพราะเราเลือกไปแล้ว

💬 ชวนกลุ่มคุย

① เราเห็นอะไรเหมือนกัน? “ข้อมูลอะไรที่ทำให้เราคิดตรงกัน?”
② เราเห็นต่างตรงไหน? “มีข้อมูลส่วนไหนที่เราอาจตีความต่างกัน?”
③ ถ้าเราได้ข้อมูลเพิ่มอีก 1 อย่าง เราอยากรู้อะไร? “ข้อมูลอะไรที่จะทำให้เราตัดสินใจเปลี่ยนสีได้?”

1

🟨 Yellow

ช่างตรวจพบว่าไฟเกี่ยวข้องกับระบบเบรก

ระบบเบรกมีค่าผิดปกติ และไม่ควรปล่อยให้ลูกค้านำรถออกไป ก่อนตรวจสอบอย่างละเอียด

🟥 Layer 2 → Red ข้อมูลใหม่เปลี่ยนประเด็นจาก “ไฟเตือนที่ยังไม่ทราบความหมาย” เป็นเรื่องที่เกี่ยวข้องกับระบบเบรกและความปลอดภัยโดยตรง

CASE 04

🟥 Red
→
🟥 Red

ข้อมูลชุดที่ 1 — Layer 1

รถเคลื่อนตัวออกจากตำแหน่งโดยไม่มีคนอยู่ในรถ พนักงานต้องถอยออกจากแนวรถ

ลูกค้าที่อยู่บริเวณนั้นเห็นเหตุการณ์และพูดว่า “เมื่อกี้รถเกือบชนคนแล้วนะ!”

🟥 Layer 1 → Red เหตุการณ์ด้านความปลอดภัยเกิดขึ้นแล้ว มีความเสี่ยงต่อชีวิตและทรัพย์สิน จึงไม่ควรรอข้อมูลให้ครบก่อนแจ้งผู้จัดการ

ข้อมูลชุดที่ 2 — Layer 2

ตรวจสอบแล้วพบว่ารถมีความเสียหายเล็กน้อยบริเวณกันชน

  • ไม่มีผู้ได้รับบาดเจ็บ
  • มีลูกค้าอยู่ในพื้นที่หลายคน
  • มีลูกค้าถ่ายวิดีโอเหตุการณ์ไว้
🟥 Layer 2 → Red ข้อมูลใหม่ไม่ได้ลดระดับความรุนแรงของเหตุการณ์ แต่ยืนยันว่ามีความเสี่ยงด้านความปลอดภัย ทรัพย์สิน และมีผู้เห็นเหตุการณ์หลายคน
LEARNING POINT

เคสสีแดงบางเรื่องไม่ต้องรอ VERIFY ให้ครบก่อนจึงแจ้ง เพราะใน Red Protocol การหยุดหรือลดความเสี่ยงต้องมาก่อน

💬 ชวนกลุ่มคุย

① เราเห็นอะไรเหมือนกัน? “ข้อมูลอะไรที่ทำให้เราคิดตรงกัน?”
② เราเห็นต่างตรงไหน? “มีข้อมูลส่วนไหนที่เราอาจตีความต่างกัน?”
③ ถ้าเราได้ข้อมูลเพิ่มอีก 1 อย่าง เราอยากรู้อะไร? “ข้อมูลอะไรที่จะทำให้เราตัดสินใจเปลี่ยนสีได้?”
CASE 05

🟧 Orange
→
🟧 Orange

ข้อมูลชุดที่ 1 — Layer 1

ลูกค้าไม่พอใจยอดค่าใช้จ่ายและเริ่มเสียงดังขึ้น

มีลูกค้าคนอื่นอยู่บริเวณนั้น จึงมีเหตุผลให้ผู้ช่วยผู้จัดการเข้ามารับทราบและช่วยจัดการ

🟧 Layer 1 → Orange เป็นเรื่องร้องเรียนที่ควรมีผู้จัดการเข้ามารับ ownership และตรวจสอบข้อมูลก่อนตัดสินใจ

ข้อมูลชุดที่ 2 — Layer 2

  • มีงานเพิ่มเติมจริง
  • มีการแจ้งราคาเพิ่มเติมก่อนดำเนินการ
  • ลูกค้าได้รับข้อมูล แต่จำไม่ได้ว่าเคยตอบตกลง
  • ไม่มีความเสียหายต่อรถหรือทรัพย์สิน
  • ยังไม่มีการขู่ว่าจะร้องเรียนหรือเผยแพร่เรื่อง
  • ลูกค้าเริ่มใจเย็นลงหลังผู้ช่วยผู้จัดการเข้ามาคุย
🟧 Layer 2 → Orange ข้อมูลใหม่ช่วยให้เห็นข้อเท็จจริงชัดขึ้น แต่ไม่ได้เพิ่มความรุนแรงถึงระดับ Red
LEARNING POINT

VERIFY ไม่ได้แปลว่า “ต้องยกระดับทุกครั้ง” บางครั้งข้อมูลใหม่ทำให้เรามั่นใจมากขึ้นว่า Orange คือระดับที่เหมาะสม

🟧 Orange
→
🟥 Red

ข้อมูลชุดที่ 1 — Layer 1

ลูกค้าโทรมาแจ้งว่าเบรกมีเสียงหลังจากนำรถเข้ารับบริการ

ลูกค้าบอกว่ายังเบรกได้ แต่ไม่สะดวกนำรถกลับมาตรวจทันที และไม่อยากเสียเวลาเข้าออกหลายรอบ

🟧 Layer 1 → Orange เป็นปัญหาที่เกี่ยวข้องกับงานบริการเดิม และควรมีผู้จัดการรับรู้และช่วยติดตาม แต่ข้อมูลตอนแรกยังไม่ยืนยันว่ามีความเสี่ยงด้านความปลอดภัยระดับสูง

ข้อมูลชุดที่ 2 — Layer 2

ลูกค้าส่งคลิปเสียงมาให้ช่างตรวจสอบ และช่างพบว่าเสียงไม่ใช่เสียงจากการเสียดสีทั่วไป

เมื่อลูกค้าทดลองเบรก พบว่าต้องเหยียบลึกกว่าเดิม และขณะนั้นกำลังจะขับรถออกไปส่งลูก

ช่างจึงไม่แนะนำให้ลูกค้าขับรถต่อ และให้หยุดการนัดแบบปกติทันที

🟥 Layer 2 → Red ข้อมูลใหม่เปลี่ยนจาก “มีเสียงเบรก” เป็นสัญญาณที่เกี่ยวข้องกับประสิทธิภาพของระบบเบรก และมีความเสี่ยงด้านความปลอดภัยโดยตรง
LEARNING POINT

ข้อมูลเล็ก ๆ ที่ดูเหมือนไม่สำคัญในตอนแรก อาจเปลี่ยนระดับของเคสได้ โดยเฉพาะเมื่อเกี่ยวข้องกับความปลอดภัย

ข้อมูลเพิ่ม → ยืนยันระดับเดิม

🟨 Yellow
→
🟨 Yellow

ข้อมูลชุดที่ 1 — Layer 1

ลูกค้ารับรถแล้วพบว่าเครื่องปรับอากาศไม่ค่อยเย็น ทั้งที่ก่อนนำรถเข้ารับบริการยังใช้งานได้ตามปกติ

ลูกค้าต้องการใช้รถกลับบ้านในวันนั้น และกังวลว่าต้องทิ้งรถไว้ที่สาขาอีก

🟨 Layer 1 → Yellow มีอาการผิดปกติที่ต้องตรวจสอบ แต่ยังไม่ทราบว่าระบบมีความเสียหายหรือมีความเสี่ยงด้านความปลอดภัยหรือไม่

ข้อมูลชุดที่ 2 — Layer 2

ช่างตรวจสอบแล้วพบว่าระบบปรับอากาศยังทำงานได้ตามปกติ แต่ต้องใช้เวลาสักระยะกว่าจะเย็น เนื่องจากรถจอดอยู่กลางแดดเป็นเวลานาน

ช่างแนะนำวิธีใช้งานและตรวจสอบเรียบร้อยแล้ว เมื่อลูกค้าทดลองอีกครั้ง แอร์เย็นและลูกค้ารับรถกลับ

🟨 Layer 2 → Yellow ข้อมูลใหม่ทำให้รู้ว่ายังไม่พบความเสียหาย และอาการสามารถอธิบายและจัดการได้โดยไม่ต้องยกระดับ
หมายเหตุสำหรับ Facilitator คะแนน 0–1–2 ของแต่ละมิติสามารถใส่ตาม Matrix เวอร์ชันที่พี่ใช้จริงได้ที่นี่ โดยไม่จำเป็นต้องเปลี่ยนโครงสร้างหน้าเว็บ
LEARNING POINT

บางครั้งข้อมูลใหม่ไม่ได้ทำให้เคสรุนแรงขึ้น แต่ช่วยให้เรามั่นใจมากขึ้นว่าเคสยังอยู่ในระดับเดิม

③ ถ้าเราได้ข้อมูลเพิ่มอีก 1 อย่าง เราอยากรู้อะไร? “ข้อมูลอะไรที่จะทำให้เราตัดสินใจเปลี่ยนสีได้?”

ข้อมูลชุดที่ 1 — Layer 1

ลูกค้ากลับมาที่สาขาและแจ้งว่าปัญหาเสียงจากล้อ ที่เคยเข้ารับบริการเมื่อสัปดาห์ก่อนกลับมาอีกครั้ง

ลูกค้าเริ่มไม่พอใจและบอกว่าไม่มีเวลามาเข้าออกหลายรอบ เพราะครั้งก่อนก็เสียเวลาไปแล้ว

🟧 Layer 1 → Orange ปัญหาเกิดซ้ำและเริ่มกระทบความเชื่อมั่นของลูกค้า จึงควรให้ผู้จัดการรับรู้และรับผิดชอบการตรวจสอบ

ข้อมูลชุดที่ 2 — Layer 2

ผู้จัดการตรวจสอบแล้วพบว่าลูกค้าเคยเข้ารับบริการด้วยปัญหาเดียวกันมาแล้วหนึ่งครั้ง และวันนี้กลับมาด้วยอาการเดิม

ช่างตรวจสอบเบื้องต้นแล้ว ยังไม่พบสัญญาณที่บ่งชี้ถึงอันตรายในการใช้งานรถ แต่จำเป็นต้องตรวจสอบเพิ่มเติมเพื่อหาสาเหตุที่แท้จริง

ผู้จัดการรับเรื่องเองและแจ้งว่าจะตรวจข้อมูลครั้งก่อน พร้อมตรวจรถเพิ่มเติมแล้วกลับมาแจ้งผลลูกค้า

🟧 Layer 2 → Orange ข้อมูลใหม่ยืนยันว่าปัญหาเกิดซ้ำและต้องได้รับการจัดการอย่างจริงจัง แต่ยังไม่มีข้อมูลด้านความปลอดภัยหรือความเสียหายที่ทำให้ต้องยกระดับเป็น Red
หมายเหตุสำหรับ Facilitator คะแนน 0–1–2 ของแต่ละมิติสามารถใส่ตาม Matrix เวอร์ชันที่พี่ใช้จริงได้ที่นี่ โดยไม่จำเป็นต้องเปลี่ยนโครงสร้างหน้าเว็บ
LEARNING POINT
